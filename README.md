# Color Playground

A small standalone Vue experiment: select one of five colors, cycle to the next shade, and preview text that automatically chooses black or white for contrast.

[Open the demo](https://qijiejin25-design.github.io/qj-library-pages/)

This repository contains only compiled static assets in `site/` and the GitHub Pages deployment workflow. The application has no external API, account system, uploaded data, source maps or embedded credentials.

A separate private build runs the contrast tests and Vue build, then automatically updates these compiled assets. A push to `site/` triggers the Pages deployment.
